{% translate "Intégration (SDK / LMS)" %}

{% translate "Ces endpoints permettent à votre plateforme d'examen — ou au SDK — d'ouvrir et de clôturer les sessions d'examen et de transmettre les événements détectés pendant l'épreuve. {# --- Signer une requête --- #}

{% translate "Signer une requête" %}

{% translate "Ajoutez deux en-têtes à chaque appel :" %}

  • X-ExamSDK-Public-Key — {% translate "la clé publique de votre projet, qui identifie l'appel." %}
  • X-ExamSDK-Signature — {% translate "la signature HMAC-SHA256 (en hexadécimal) calculée avec votre clé secrète." %}

{% translate "La signature se calcule sur les données envoyées. Ajoutez à ces données un horodatage" %} issued_at {% translate "(en secondes) proche de l'heure réelle :" %}

{% translate "Endpoint" %}{% translate "Données à signer" %}
sessions /project_id|exam_id|student_id|issued_at
sessions /close/project_id|session_id|issued_at
events /project_id|session_id|issued_at
logs /project_id|sdk-logs|issued_at

{% translate "Sur les appels GET (sans corps), placez les données à signer dans l'URL." %}

{% translate "Signer en Python" %}

{% code_block "doc-machine-sign-python" "python" "sign.py" %} import hashlib import hmac import time SECRET_KEY = "sk_live_..." # clé secrète du projet (jamais exposée au navigateur) PROJECT_ID = "3c8e1f2a-9b47-4d0e-8a11-2f6c9d4b7e01" def sign(canonical: str) -> str: return hmac.new(SECRET_KEY.encode(), canonical.encode(), hashlib.sha256).hexdigest() issued_at = int(time.time()) canonical = "|".join([PROJECT_ID, "MATH-2024-S1", "etu-1042", str(issued_at)]) signature = sign(canonical) {% endcode_block %}
{# --- Ouvrir une session --- #}

{% translate "Ouvrir une session d'examen" %}

{% translate "Appelez cet endpoint au démarrage de l'épreuve d'un étudiant : il ouvre la session de surveillance et vous renvoie son identifiant, à réutiliser pour envoyer les événements.
